## 2. 功能验收

### 2.1 免费版（未购买 Pro）
- [ ] 关卡 1-10 可玩
- [ ] 关卡 11-50 显示锁定，点击弹出付费墙（PaywallReason.LEVELS）
- [ ] 笔记、撤销、重做 可用
- [ ] 每关提示 3 次，用完后不可用
- [ ] 浅色 / 深色 / 跟随系统 三种主题可用
- [ ] 每日挑战、限时挑战 点击弹出付费墙（PaywallReason.CHALLENGE）
- [ ] 统计页 点击弹出付费墙（PaywallReason.STATS）
- [ ] 设置页 Pro 区块显示"解锁 Pro"

### 2.2 Pro 版（已购买 / 本地解锁）
- [ ] 关卡 1-50 全部可玩
- [ ] 提示显示"提示 (∞)"，无限制使用
- [ ] 每日挑战、限时挑战 可进入
- [ ] 统计页可进入，显示完整数据
- [ ] 设置页 Pro 区块显示"Pro 已解锁" + ✓
- [ ] 付费墙显示"Pro 已解锁" + "开始游戏"

### 2.3 购买流程
- [ ] 点击购买 → 弹出 Play 结算面板
- [ ] 购买成功 → Toast "Pro 已解锁，感谢支持！" + UI 即时刷新
- [ ] 取消购买 → Toast "已取消购买"
- [ ] 网络异常 → Toast "购买失败，请重试" / "计费服务不可用"
- [ ] 恢复购买 → 有记录则"购买已恢复"，无则"未找到历史购买记录"
- [ ] 重启应用 → Pro 状态保持

### 2.4 语言切换
- [ ] 8 种语言（en, zh-Hans, zh-Hant, ja, ko, es, fr, de）+ "跟随系统"
- [ ] 设置页语言 chip 点击 → 即时生效，无需重启
- [ ] 所有文案无硬编码中文（除调试预览）
- [ ] 占位符 `{n}`、`{price}` 等在所有语言中保留

### 2.5 离线特性
- [ ] 飞行模式下完整可玩
- [ ] 无网络请求（Charles/Proxy 抓包无流量）
- [ ] 进度本地保存，卸载即清除
